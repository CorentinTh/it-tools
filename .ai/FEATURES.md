## Snapshot and selection method

All 710 issues and 997 pull requests in the snapshot dated 2026-07-12 were analyzed. The backlog contains many duplicates, translations, dependency-bot PRs, and ideas that would turn the product into a backend/SaaS. The list below retains features that fit the local product model: developer-first, client-side, self-hostable, offline where practical, and no transmission of user data by default.

A second-pass review on 2026-07-13 compared every item not already cited by the audit, then separately reviewed open PRs, open feature/bug issues, closed-unmerged proposals, and closed bug reports against the local source. The GitHub API still reported #1832 as the newest repository item, so the saved JSON snapshot remained complete.

An open PR is a source of requirements and test cases, not permission to cherry-pick it. Implementations must be adapted to the local branch.

## Defer or reject without a separate product decision

- The REST API/server layer in [PR #1819](https://github.com/CorentinTh/it-tools/pull/1819) changes the trust model, deployment, and operational complexity. It is a separate product, not a normal tool.
- The login/token gate in [PR #1574](https://github.com/CorentinTh/it-tools/pull/1574) cannot be secure in a static SPA alone; use an identity-aware proxy or backend if access control becomes a requirement.
- Persisting OTP secrets as proposed by [PR #1221](https://github.com/CorentinTh/it-tools/pull/1221) conflicts with the privacy policy. Explicit query import and non-persistent session state are acceptable alternatives.
- GeoIP, currency, public-IP, loan, and other API-backed ideas require a provider, SLA, privacy disclosure, and offline fallback; deterministic local tools should come first.
- Restoring all upstream translations is not planned: this fork is intentionally English-only. That requires a separate product decision rather than mechanical synchronization.
- Lifestyle calculators, random games, national-ID generators, and similar proposals are outside the developer/DevOps-first scope unless the product direction changes.
- Active network scanning/ping of arbitrary hosts is constrained by browser security and can create abuse/privacy risks; offline calculators and explicit DoH/HTTP tools are preferred.
- JavaScript obfuscation/deobfuscation, OCR, PDF mutation, HEIC/video processing, and other large WASM workloads should wait for worker, cancellation, memory, and bundle-budget infrastructure.
- Cloudflare/D1 favorites, temporary file sharing, and other hosted persistence proposals change the static/local trust boundary and require a separate backend product decision.
