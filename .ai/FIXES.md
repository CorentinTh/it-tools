# Potential Fixes from Upstream and the Local Audit

- **DONE:** Token/TOTP secure randomness implementation, missing alphabet characters, duplicate-symbol removal, deterministic unit coverage, and first production/route-smoke checkpoint.

- **DONE:** Dev no longer shares an ambiguous origin with preview or Orca's own Vite runtime. IT Tools dev is strict on `127.0.0.1:8091`, preview is strict on `127.0.0.1:5050`, `dev:fresh` forces Vite dependency re-optimization, dev responses are `no-store` and mode-labelled, and dev startup removes only the root IT Tools Workbox registration/application caches before a bounded one-time reload. Worker-only dependencies are explicitly included/excluded from Vite 4 optimization, preventing first-use reloads that previously abandoned JSON/Math/XML workers. Lazy-route-only `jsonc-parser`/Monaco/Mermaid plus worker-owned `hyparquet`/`saxen` and worker-transitive `js-base64`/`hash-wasm` are prebundled too; their source contract is unit-tested and the current clean traversal covers 129 routes without optimizer restart. Its local central-directory/part reader rejects unsafe, duplicate, overlapping, ZIP64, encrypted, malformed, oversized, CRC-invalid, macro-bearing, DTD/entity/processing-instruction, and unsafe-relationship input before publishing metadata or one bounded selected page. Native raw-DEFLATE output and every XML/output layer have independent limits; formulas and external links are never executed/fetched; errors are static; values and files remain ephemeral. Exact `saxen@11.1.1` has zero audit paths.

PAR1/footer/schema/row-group/column metadata, offsets, nesting, selected chunk bytes, cumulative Blob reads, page/cell/output size, runtime, replacement, cancellation, and disposal are independently bounded; errors are static and never echo file content. Exact dependency-free `hyparquet@1.28.2` has no target audit path.
- **DONE:** Mermaid rendering is restricted to five reviewed diagram families, exact patched `mermaid@10.9.8`, fixed strict configuration, active-content/source rejection, independent SVG sanitization and resource bounds, and a scriptless network-denying sandbox. ## Summary

All 710 issues and 997 pull requests were analyzed. The upstream backlog contains many duplicates and reports against old releases, so each item below is classified as:

- **locally confirmed** — reproduced through code inspection, a focused probe, or a standard project command;
- **likely current** — the relevant path exists in current code, but a regression fixture or browser reproduction is still required;
- **verify release/cache** — the source may already contain a fix while the report refers to an old Docker/PWA artifact.

## Required verification for every fix

1. Add a regression fixture from the issue, including Unicode, large, malformed, and boundary inputs.
2. Put pure behavior in unit tests and use Playwright for UI/lifecycle only.
3. Verify size limits, cancellation, and error states; UI must never disappear on invalid input.
4. Run lint, typecheck, unit tests, route smoke tests, and production build.
5. When the deferred dependency/base-image security track resumes, rerun its audit/scan and document residual risk there.
