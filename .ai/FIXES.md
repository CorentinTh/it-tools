# Potential Fixes from Upstream and the Local Audit

## Summary

All 710 issues and 997 pull requests were analyzed. The upstream backlog contains many duplicates and reports against old releases, so each item below is classified as:

- **locally confirmed** — reproduced through code inspection, a focused probe, or a standard project command;
- **likely current** — the relevant path exists in current code, but a regression fixture or browser reproduction is still required;
- **verify release/cache** — the source may already contain a fix while the report refers to an old Docker/PWA artifact.

## Reports that should not be treated as current bugs without reproduction

- UTF-8 Base64 reports [#909](https://github.com/CorentinTh/it-tools/issues/909) and [#1023](https://github.com/CorentinTh/it-tools/issues/1023) do not reproduce: the current `js-base64` path round-trips `今天 💩`. Add regression tests and classify the old reports as stale instead of replacing the encoder.
- Favorite-button reports [#940](https://github.com/CorentinTh/it-tools/issues/940), [#1384](https://github.com/CorentinTh/it-tools/issues/1384), [#1424](https://github.com/CorentinTh/it-tools/issues/1424), [#1639](https://github.com/CorentinTh/it-tools/issues/1639), [#1692](https://github.com/CorentinTh/it-tools/issues/1692), and [#1707](https://github.com/CorentinTh/it-tools/issues/1707) continued after merged fix [#1368](https://github.com/CorentinTh/it-tools/pull/1368). Verify stale Docker images, service-worker cache, and route/base behavior first; path-based storage in current source appears correct.
- Old Docker build failures [#442](https://github.com/CorentinTh/it-tools/issues/442) and [#453](https://github.com/CorentinTh/it-tools/issues/453) target an older toolchain. Current build passes but remains expensive (51 s and 24,599 modules), so collect build-memory benchmarks rather than copying old workaround [#1073](https://github.com/CorentinTh/it-tools/pull/1073).
- YAML merge/anchor report [#1333](https://github.com/CorentinTh/it-tools/issues/1333) is already covered in the local branch: YAML-to-JSON uses `parseYaml(value, { merge: true })` and has an E2E fixture for merge keys. Preserve that regression test during YAML upgrades.
- [Issue #1649](https://github.com/CorentinTh/it-tools/issues/1649) contains no technical report and is not a finding.

## Required verification for every fix

1. Add a regression fixture from the issue, including Unicode, large, malformed, and boundary inputs.
2. Put pure behavior in unit tests and use Playwright for UI/lifecycle only.
3. Verify size limits, cancellation, and error states; UI must never disappear on invalid input.
4. Run lint, typecheck, unit tests, route smoke tests, and production build.
5. For dependency/container fixes, rerun audit/scan and document residual risk.
